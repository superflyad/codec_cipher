# Codec Cipher Roadmap

Codec Cipher is an experimental dimensional laboratory. This roadmap describes planned capability phases without committing to a specific release schedule.

## Phase 1: Laboratory Foundation

- Create dimensional objects.
- Classify square, cube, hyperdimensional, and unstable objects.
- Save and load objects.
- Inspect object vertices.

## Phase 2: Experiment State

- Mutation system.
- Compare object states.
- Object history tracking.
- Experiment logs.

## Phase 3: Dimensional Interface

- Richer terminal UI.
- Projections of higher-dimensional objects.
- Object stability scoring.

## Phase 4: Cipher Research

- Reversible transformations.
- Encoding and decoding experiments.
- Early cipher research.
